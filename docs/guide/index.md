# 使用指南

欢迎来到**射手座学习导航**的文档中心。这里是站点的知识仓库：所有学习文档按分类集中管理，并支持随时新增文档或模块。

## 站点结构

本站基于 [VitePress](https://vitepress.dev) 构建，整体分为三部分：

| 模块 | 说明 |
| --- | --- |
| **文档中心**（本目录） | Markdown 文档，按分类组织在 `docs/` 下，侧边栏自动生成 |
| **功能页面** | 登录 / 注册 / 学习门户 / 管理后台，位于 `docs/public/`，保留原有页面样式 |
| **访客首页** | 由 `docs/index.md` 渲染，视觉与原首页一致 |

## 文档分类

当前文档按以下分类组织：

- **使用指南** — 本目录，站点使用与扩展方法
- **前端开发** — HTML / CSS / JavaScript 等
- **后端开发** — API 设计、服务端技术
- **开发工具** — 编辑器、版本控制、命令行工具

每个分类对应 `docs/` 下的一个目录，目录内的每一篇 Markdown 就是一个文档。
